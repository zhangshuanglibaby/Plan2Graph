## 可复现的最短演示

工作目录为 `server/`；在已按 [README](../README.md) 安装的环境中，先确认将要发送的**具体**输入已获 DeepSeek 传输授权，且本地已配置密钥。以下成功命令使用公开在仓库中的合成练习计划 `doc/plan.md`，**不是**五条真实 Agent 计划；每次运行都会发送其完整文本，不能把演示命令当作免授权的离线检查。

```bash
.venv/bin/plan2graph generate doc/plan.md -o doc/plan.mmd
```

预期退出码为 `0`，终端标准错误显示任务数量与待确认关系，`doc/plan.mmd` 保存 Mermaid 源码；输出内容随模型回答而变，不保证与旧截图相同。用支持 Mermaid 的本地预览查看图。Markdown 预览不是官方 `mmdc` 的整批渲染验收。

无需密钥、无需网络的失败命令（不会发送文本）：

```bash
.venv/bin/plan2graph generate - < /dev/null
```

预期退出码为 `2`，标准错误为“输入为空：请提供非空计划文本。”，标准输出为空；IDE 终端可在命令结束后查看退出码。若二进制尚未安装，应先按 README 安装；未安装时的 shell 错误不是此处的 CLI 失败案例。真实模型异常会返回另一类退出码，不能用这个空输入例子代替。

本窗口在 `server/` 实际执行了上述空输入命令，得到退出码 `2` 和预期提示；还执行了新增测试 `3 passed`、全量离线测试 `249 passed`。这些测试未调用 DeepSeek，不能用作模型质量指标。成功演示命令在本窗口**未执行**，因为本窗口未取得该具体练习原文新的传输授权。

要继续正式验收：先获得五条来源可复核的真实 Agent 计划，逐条完成隐私检查与两路传输授权，再固定请求参数和人工基准；保留所有失败、运行官方 `mmdc`，完成逐条人工裁定与四项指标。无法取得真实计划时，应维持未验收结论，不把 S01–S05 的模拟文本改名。
