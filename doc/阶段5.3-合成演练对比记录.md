- 两侧均使用同一份输入文件，运行前记下该文件的 SHA-256 内容指纹；指纹不同则停止该例比较。
- 先固定直接生成 Mermaid 的提示词全文及版本，再运行任何样例。两侧的提示词和输出格式因方法不同，可以不同，但必须保存原样；不因看到结果而只修改某一侧的提示词。
- 每侧分别记录请求时的模型别名、响应中的模型标识、可核实的服务端版本、请求时间、`max_tokens`、温度及其他实际传入参数、超时、输出格式、请求次数、连接重试次数和结构修复次数。没有显式传入的参数写“未传”，查不到的版本写“未确认”。`deepseek-flash` 只是默认别名，不是已核实的服务端版本。
- 记录两侧完整的原始响应、原始 Mermaid 文本、诊断和失败。Plan2Graph 的 CLI 只提供 Mermaid 与诊断，不包含完整结构化图；不能从 Mermaid 反推引文或图快照。S01 的独立采集入口是 `scripts/compare_synthetic_s01.py`，其结果只保存在被 Git 忽略的 `.local/phase5_3_s01/`。
- 先保留未经人工修改的输出并检查结构；官方 `mmdc` 实际解析、渲染成功后，才能写“可渲染”。若渲染器未安装或未运行，填“未核验”，不能填“通过”。
- 两侧都以人工复核的关键任务和确定依赖为参照，记录漏任务、无依据或方向错误的实线；候选虚线与确定实线分开。所有失败案例都保留，不能只展示成功样例。
