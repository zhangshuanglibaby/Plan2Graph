## 待复核与禁止推断

- G3 与 G6：第 5 条明确页面静态布局可与上传接口并行，不得因条目顺序画确定边。
- G4 与 G5：原文同时要求列表与下载，没有说下载接口的开发必须等待列表接口完成；不要仅凭“列表与下载”四字画边。
- G6 → G7、G6 → G8 或 G6 → G9：布局先做不必然构成接口接入的确定前置，原文仅把“接口可用后”写成接入条件；若模型画此类边，先复核而非直接算正确。
- G2 → G5 或 G2 → G10：下载与删除清理需要找到附件，但是否必须等完整元数据设计完成才开始开发，原文未明确；先不列确定边。
- 第 4 条“先验证权限，再读取文件”是 G5 的**运行时安全门槛**；第 6 条“清理可以异步进行”允许工单删除与清理分步发生。不能由这两句推断 G5 与 G10 之间有开发依赖。
- “附件不能通过公开链接直接访问”是上传存储和下载访问的约束，不是要求新增公开文件服务。
