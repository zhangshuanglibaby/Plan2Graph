## 待复核与禁止推断

- G3 与 G7：第 5 条明确消息模板可与查询接口并行准备，不得画两者之间的确定边。
- G4 与 G3：第 4 条写页面布局可以先做，不要求查询接口先完成；也不能仅凭“先做”推断 G4 必须早于 G3。
- G3 → G8：定时任务必须复用**查询口径**，但原文未明确必须等待查询接口的实现代码完成；当前只列 G1 → G8，G3 → G8 待复核。
- G4 → G5、G5 → G6：静态布局、数据展示与阈值编辑可能在实现中衔接，但原文没有明确这些开发交付物必须按该顺序完成，先不列为确定边。
- G7 → G8 或 G8 → G9：实际发送需要模板和发送记录，但这些组件可以并行开发；不要把运行时共同参与一次提醒推成明确的开发先后。若输出此类边，逐项核对表达的是运行时门槛还是实施顺序。
- 不要把“沿用现有库存数据”理解为新增一套手工维护库存的任务，也不要把停用商品列入预警。
