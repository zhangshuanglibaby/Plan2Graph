# Plan2Graph

仅处理“把当前 Agent 计划成图”的请求。不要把一般项目规划、计划讨论或执行任务视为触发条件。抽取、依赖判断和结构校验由现有 CLI 负责。

## 选取计划

从当前对话中选取用户指定的完整 Agent 实施计划；用户未指定时，选取最近一份明确、完整的 Agent 实施计划。不要假设 CLI 能读取对话历史，也不要自行补写缺失的计划内容。存在多份可能的计划或内容不完整时，先请用户明确要转换的文本。调用 CLI 前，告知计划文本会发送至 DeepSeek，并取得用户明确允许。

选取时保留计划原文；向用户确认输入时，只说明选取的原文范围，不用箭头重写步骤，不添加“依赖”等原文未明确表达的判断。在 CLI 返回结果前，不自行抽取任务或判定任务关系。

## 调用 CLI

取得用户允许后，在 `server/` 工程目录使用已安装的 `./.venv/bin/plan2graph generate -`。这里的 `-` 表示 CLI 从标准输入读取计划；将选定的计划原文作为标准输入，不把整段计划拼进命令参数。分别保留标准输出中的 Mermaid 源码和标准错误中的摘要、待确认事项及错误。若命令不可用或返回非零状态，报告实际错误，不自行生成一张替代图。

## 安全传递计划

优先使用执行工具独立的标准输入通道，将完整计划原文传给 `./.venv/bin/plan2graph generate -`，不要把原文插入 shell 命令、命令参数或可执行脚本。若工具不能直接发送标准输入，可在系统临时目录创建仅当前用户可读写的临时文件，以不经过 shell 解释的方式写入原文，再将该文件重定向为 CLI 的标准输入；无论成功或失败都要清理临时文件。不要把计划原文作为临时文件留在仓库内。若无法保证安全传递和清理，停止执行并请用户提供可读取的计划文件。

## 展示结果

尚未选定唯一完整计划、尚未取得明确授权，或 CLI 未成功返回 Mermaid 源码时，不得自行绘制或展示任何任务图，包括多份备选计划的分支图；此时只提出澄清问题或如实报告阻碍。

仅在 CLI 成功退出后，原样把 Mermaid 源码放入标记为 `mermaid` 的代码块，并简要转述标准错误中的任务数量、确定依赖、待确认关系及被跳过关系的原因。虚线候选关系是待确认事项，不得称为已证实的前置条件，也不等于生成失败。默认从标准输出取得图，并说明未写入文件；只有用户明确要求保存时才使用 `-o`，成功后从实际生成的文件读取图并报告其路径。若目标文件已存在，先征询是否覆盖。失败时只报告退出状态和错误，不展示旧图或声称已生成文件。
